Start here

Add an update with the Add button or press Q from any page. Use Import for an existing CSV, Excel, or PDF file. Complete text updates are added after processing and can be undone for ten minutes. Voice captures and imports wait for your review.

Shared and Only you

Shared records are visible to both active adults. Only you records are visible only to you and never shape your partner’s Home or This week. Choose the visibility that fits each update or import.

Records

Money shows exact totals and recorded changes, not financial advice. Health keeps reported values and dates together without diagnosis, clinical interpretation, or treatment recommendations. Calendar keeps household dates and plans connected; calendar exports open one-time drafts for your review and never sync in the background.

Home and This week

Your Home and This week bring together updates you can access. Shared updates appear for both partners; private updates stay in Only you. Mithra does not decide, diagnose, mediate, or judge for either partner.

How Mithra uses a model provider

A model provider is optional and runs only when you ask Mithra to capture, import, or regenerate AI insights. Mithra sends only the records visible to you that the action needs. Clear text updates may be added immediately with an Undo option; imports wait for your approval. The household owner manages the provider, model, address, and encrypted key in Settings. Voice updates and visual-PDF reading need OpenAI.

PDFs without readable text

Mithra reads PDFs on your server first. If a PDF contains only images, Mithra asks before sending that one file to OpenAI to read the visible pages. Cancelling sends nothing and deletes the uploaded file.

Health corrections

If values cannot be compared safely, Mithra keeps them separate until you enter a corrected value and unit. The original source remains linked; Mithra does not guess a conversion.

Calendar exports

Downloading an .ics file or opening a Google Calendar draft creates a one-time export. Later Mithra changes do not update another calendar.

Deleting a source and recovery

Deleting a source also removes the records and unfinished actions that depend on it. If the encrypted file cannot be removed immediately, Mithra finishes the job automatically. A deleted source cannot be opened again.
